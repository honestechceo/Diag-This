How it works: Coil-on-plug, 4 cylinders, firing order 1-3-4-2. Each coil has pin 1 power, pin 2 ground and pin 3 the IGT trigger from the ECM. Start the engine, then put Scope A and Scope B on test points to see the waveforms. The kV points are secondary pickups clipped on each coil. The meter only shows averages, so the scope will tell you more.
